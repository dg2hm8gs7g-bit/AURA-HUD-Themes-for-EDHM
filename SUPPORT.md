# Support

## Report here

Open an issue in this repository for:

- AURA palette, contrast, or shield-colour problems
- Incorrect AURA theme names or previews
- A missing or damaged release ZIP
- Documentation or checksum discrepancies

Include the theme name, affected Elite Dangerous screen, EDHM UI version, expected
appearance, actual appearance, and a screenshot when practical.

## Report to EDHM

Use EDHM's official support channels for installation failures, game detection,
shader/runtime errors, or problems that also affect non-AURA themes.

Never publish account credentials, authentication tokens, private correspondence,
or logs containing information you do not want shared publicly.
