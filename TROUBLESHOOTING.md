# Troubleshooting

## The theme imported but did not change the HUD

Confirm that EDHM UI points to the Elite Dangerous Live/Odyssey installation,
select the imported AURA theme, choose **Apply Theme**, and follow EDHM UI's reload
or game-restart prompt.

## An old preview or colour scheme is still displayed

EDHM UI may cache a same-named theme. Remove the older copy through EDHM UI, close
and reopen EDHM UI, import the replacement ZIP, and apply it again.

## The complete collection will not import

The complete download is an outer archive. Extract it once, then import the desired
individual `AURA - Theme Name.zip` files. Do not extract the individual theme ZIPs.

## A specific screen has poor contrast or an unexpected colour

Capture the affected screen, record the AURA theme name, Elite Dangerous mode, and
EDHM UI version, then open an issue in this repository. Do not include Commander
credentials, journals, logs containing personal paths, or account data.

## EDHM UI itself will not install or apply any theme

Use EDHM's official documentation and support channels. This repository supports
the AURA theme packages and their presentation, not the EDHM runtime.
