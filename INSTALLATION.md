# Installation

## Individual theme

1. Download the chosen `AURA - Theme Name.zip` release asset.
2. Start EDHM UI and confirm the correct Elite Dangerous Live installation is
   selected.
3. Use EDHM UI's theme import command and select the ZIP.
4. Select the imported AURA theme and apply it.
5. Follow EDHM UI's reload instructions.

## Complete collection

1. Download `AURA-Master-HUD-Complete-vX.Y.Z.zip`.
2. Extract this outer collection archive once.
3. Import the individual theme ZIPs you want into EDHM UI. Do not extract those
   inner ZIP files.

## Updating a theme

EDHM UI may cache an existing theme and its preview when a same-named package is
imported again. Remove the previous theme through EDHM UI, restart EDHM UI, and
then import the replacement package.

## Important

Only use AURA packages from this repository's Releases page. Obtain EDHM and
EDHM UI separately from their official project sources.
